
# MafrimDocs — releases

Release information for MafrimDocs, an offline-first PDF viewer, editor and
annotator.

Each release lists what changed, and carries the downloads for it.

## Checking for updates

MafrimDocs looks here only when you choose **Check for Updates** from the Help
menu. There is no check when the app starts, no background polling and no
telemetry.

The check asks for release information and nothing else. It sends no document,
no filename, no identifier and no account. It downloads and installs nothing —
it tells you what the newest version is and offers to open its page, so
replacing the application stays a decision you make where you can see what you
are agreeing to.
